# 二维码标签插件 操作指南（v1.8.12）

> 适用：GLPI 12 / qrcodelabel 1.8.12
> 打印机：GP-1134T（300 dpi，USB 直连，浏览器打印路线，无需服务器访问打印机）

---

## 1. 单个资产打印（浏览器直打）

1. 打开任一支持的资产（计算机 / 显示器 / 打印机等）；
2. 切换到 **二维码标签** 标签页；
3. 设置 **份数**（每份一页）；
4. 点击 **打印（浏览器）**，页面自动弹出浏览器打印对话框；
5. 选择 GP-1134T，确认 **缩放 100%（不缩放）**，点击打印。

> 每页是一张与标签纸 1:1 的 300 dpi 图像，浏览器只负责送纸，尺寸由 `@page` 精确控制。

## 2. 列表页批量打印（浏览器直打）

1. 在资产列表页勾选多台设备（可跨类型混选）；
2. 顶部 **批量操作** 下拉框中选择 **二维码标签 - 浏览器打印（批量）**；
3. 选择打印配置与份数，点击 **打印（浏览器）**；
4. 浏览器打开打印页，**每个资产一页**（份数即页数），并自动弹出打印对话框。

说明：

- 批次保存在服务器会话中，**30 分钟过期**，过期后重新执行批量操作即可；
- 渲染前会逐条重新校验读取权限，无权限的资产不会出现在打印页。

## 3. 批量生成 PDF / ZIP（下载归档）

勾选多台设备 → 批量操作 → **二维码标签 - 打印二维码标签** → 生成。
生成结果保留在 插件下载页（`front/download.php`），提供 PDF / ZIP 下载按钮，适合归档或外协打印。

## 4. 打印方向（内容旋转）

热敏驱动自己决定纸张方向，浏览器对话框改不了。如果打印出来是竖着打 / 被裁断：

1. 在打印页上用 **0° / 90° / 180° / 270°** 按钮逐个试，直到方向正确；
2. 找到正确角度后，到 **配置 → 设置 → 打印方向** 固化保存，之后所有打印页默认该角度。

## 5. 管理员配置（配置 → 二维码标签）

| 配置项 | 说明 |
|---|---|
| 磁带尺寸 | 必须与实际标签一致。GP-1134T 当前使用 **90 × 40 mm (GP-1134T)** |
| 颜色模式 | 黑白 / 单色 / 彩色 / 反色等 |
| 行距 | 1.00 = 紧凑且字号不变；1.30 / 1.50 / 1.80 逐级放宽（整块空气均分） |
| 打印方向 | 0 / 90 / 180 / 270，见第 4 节 |
| 输出格式 | PDF 或 PNG |
| 保存位置 / 日期 / 所有者 | 标签底部信息行 |

**打印配置（profiles）**：可保存多套组合（如 Standard / NOuser），每套含独立的磁带尺寸、颜色模式、行距等，并指定一套为默认。资产标签页和批量打印都可选择使用哪一套。

---

## 6. GP-1134T 驱动侧一次性设置（重要）

| 驱动设置项 | 值 |
|---|---|
| 纸张尺寸 | 宽 90 mm × 高 40 mm（自定义介质） |
| 方向 | 与第 4 节测得的角度配合 |
| 缩放 | **100%（不缩放 / 实际大小）** |
| 打印模式 | **热转印**（银色 PET 必须用树脂碳带） |
| 浓度 | 8–12（先 10 试） |

## 7. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 只打印 1 次却出 2 张 | 已修复（1.8.9）。若仍出现，确认浏览器是新版并 Ctrl+F5 强刷 |
| 二维码出墨、文字不出墨 | 碳带 / 模式问题：确认驱动为**热转印**模式 + **树脂碳带** + 浓度 8–12；可用 `tools/calib-90x40.html` 校准页隔离 |
| 打印与预览不一致（变小） | 驱动对话框里选了"适应页面"，改为 **100%** |
| 无论横竖都竖着打 / 被裁断 | 驱动拥有方向决策权，用第 4 节角度按钮解决 |
| 标签宽度改了保存又变回 36mm | 已修复（1.8.11）。若仍出现，Ctrl+F5 强刷配置页 |
| 批量打印提示"打印任务已过期" | 批次 30 分钟过期，重新执行批量操作 |
| 打开浏览器打印页没有弹出对话框 | 手动 Ctrl+P；页面加载 350ms 后会自动触发一次 |

## 8. 版本与回滚（管理员）

- 当前生产版本：**1.8.12**（149 测试同版本）；
- 发布前备份：`/root/qcl-backup-1.8.7-before-1.8.12/`（完整插件目录 + configs/printprofiles 数据快照）；
- 回滚方法（需管理员，谨慎操作）：
  ```bash
  rm -rf /var/www/html/glpi/plugins/qrcodelabel
  cp -a /root/qcl-backup-1.8.7-before-1.8.12/qrcodelabel /var/www/html/glpi/plugins/qrcodelabel
  chown -R www-data:www-data /var/www/html/glpi/plugins/qrcodelabel
  mysql glpi < /root/qcl-backup-1.8.7-before-1.8.12/data.sql   # 先核对表结构
  cd /var/www/html/glpi && sudo -u www-data php bin/console plugin:install qrcodelabel --force && \
      sudo -u www-data php bin/console plugin:activate qrcodelabel && \
      sudo -u www-data php bin/console cache:clear
  ```
- 版本历史：1.8.8 浏览器打印 → 1.8.9 90×40 + 空白页修复 → 1.8.10 打印方向 → 1.8.11 磁带尺寸保存修复 → 1.8.12 批量浏览器打印。详见 README Changelog。
